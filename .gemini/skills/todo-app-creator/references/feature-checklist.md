# Todoアプリ機能チェックリスト

Todoアプリを「実用的」かつ「洗練された」ものにするための機能チェックリストです。

## 基本機能 (MVP)
- [ ] **タスクの追加**: テキスト入力による新しいタスクの作成。
- [ ] **タスクの一覧表示**: 登録されたタスクのリスト表示。
- [ ] **完了/未完了の切り替え**: チェックボックス等による状態変更。
- [ ] **タスクの削除**: リストからのタスク削除。

## 応用機能 (利便性向上)
- [ ] **フィルタリング**: 「すべて」「完了」「未完了」の表示切り替え。
- [ ] **一括削除**: 完了済みのタスクをまとめて削除。
- [ ] **編集機能**: 既存タスクのテキスト編集。
- [ ] **永続化**: `localStorage` を使用したデータの保存。
- [ ] **空状態の表示**: タスクがない時のガイドメッセージ。

## 高度な機能 (差別化)
- [ ] **優先度設定**: 「高」「中」「低」などのラベル付け。
- [ ] **期限設定**: 期限（締切日）の設定と残り日数の表示。
- [ ] **検索機能**: キーワードによるタスクの絞り込み。
- [ ] **並べ替え**: 作成日時順、期限順、ドラッグ＆ドロップによる手動ソート。
- [ ] **カテゴリー/タグ**: タスクの分類機能。
- [ ] **統計情報**: 完了率や残りタスク数のカウント表示。
- [ ] **アニメーション**: 追加、削除、完了時の滑らかな遷移。
