# Todoアプリ UI/UX パターン

Todoアプリのユーザー体験を高めるためのUIデザインパターンです。

## 入力フォームのインタラクション
- **空の入力を防ぐ**: `trim()` を行い、空文字の場合は追加ボタンを無効化する。
- **Enter キーでの送信**: ボタンをクリックする手間を省く。
- **入力後の自動フォーカス**: 連続してタスクを追加しやすくする。

## タスクリストの視認性
- **完了済みタスクの減光**: `opacity` を下げる、または打ち消し線を引いて完了状態を明確にする。
- **優先度の色分け**: 高は赤、中はオレンジ、低は青など。
- **締切間近の強調表示**: 今日や明日が期限のタスクを色付け。

## 状態フィードバック
- **削除確認ダイアログ**: 間違って削除するのを防ぐ（特に削除不可の設定の場合）。
- **トースト通知**: 「タスクを追加しました」などの一時的な完了通知。
- **カウント表示**: 未完了のタスク数を常に画面のどこかに表示。

## Empty State (空の状態)
- **何も表示しないのはNG**: 「タスクはありません。上のフォームから追加してください！」といったガイドを表示。
- **イラストの活用**: ゆるいイラストなどを使ってアプリに「味」を出す。

## フィルタリング/ソート
- **ボタンのアクティブ状態**: どのフィルタが選択されているか視覚的に区別する。
- **件数表示**: 各フィルタ（すべて(10), 完了(3)など）の件数をバッジで表示。
